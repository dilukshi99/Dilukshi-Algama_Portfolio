# Dilukshi Isanka Portfolio

This project recreates the supplied UI design as a responsive HTML/CSS/JavaScript portfolio.

## Files
- index.html
- style.css
- script.js
- assets/hero_person.png
- assets/about_person.png
- assets/ellytrack.png
- assets/flower.png

## Run
Open `index.html` in your browser.

## Replace images
The included images are cropped from the supplied design reference so the page can run immediately.
For your final portfolio, replace them with your original high-resolution files using the same filenames.

## CV
Put your CV PDF inside `assets/` and change the Download CV link in `index.html`.

## Contact
The form opens the visitor's email client and prepares an email to:
dilukshiisanka@outlook.com

Change the email, WhatsApp, LinkedIn, GitHub and Behance links to your real accounts before publishing.
